**A smart Chrome extension to streamline your job application process. Auto-detect job postings, fill forms instantly, and track your applications across LinkedIn, Indeed, Glassdoor, and more.**

> ⚠️ **Disclaimer**: This extension is for educational purposes. Always review applications before submitting and respect job platforms' Terms of Service.

![JobApply Pro Demo](screenshots/demo.gif)

---

## ✨ Features

- 🔍 **Auto-Detect Job Postings** - Scans open tabs for job listings
- 📝 **Smart Form Filler** - Auto-fills application forms with your profile
- 💾 **Profile Management** - Save your info once, use everywhere
- 📊 **Application Tracker** - Track jobs applied, pending, and responses
- 🎨 **Clean UI** - Modern, intuitive interface
- 🔒 **Privacy First** - All data stored locally in Chrome storage
